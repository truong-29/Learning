# Bài 12 — OOP cơ bản (class, object) · Bài tập

> Track: Cơ bản (Beginner) · Module 1 · Bài 12
>
> **Độ khó: Trung bình (Medium)**

Các bài này kết hợp OOP với `raise` (Bài 11), kế thừa, và file JSON (Bài 10).

1. Tạo class `TaiKhoanNganHang` với `so_du`, các method `nap_tien(so_tien)` và `rut_tien(so_tien)`. Khi rút quá số dư thì báo lỗi (dùng kiến thức `raise` từ Bài 11) và không cho rút.
2. Dùng kế thừa: tạo class cha `PhuongTien` có `ten` và method `di_chuyen()`. Tạo class con `XeMay` và `OTo` kế thừa, mỗi loại in ra cách di chuyển riêng.
3. Kết hợp OOP + file JSON (Bài 10): tạo class `GhiChu` lưu danh sách ghi chú, có method `them(noi_dung)`, `luu_file(ten_file)` (ghi ra JSON) và `tai_file(ten_file)` (đọc lại từ JSON).

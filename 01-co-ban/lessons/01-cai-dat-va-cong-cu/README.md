# Bài 01 — Cài đặt Python & công cụ

> Track: Cơ bản (Beginner) · Module 1 · Bài 01

## 🎯 Mục tiêu bài học
- Cài đặt được Python trên máy tính của bạn và kiểm tra nó đã hoạt động.
- Cài đặt và làm quen với VS Code — công cụ để viết code.
- Chạy được dòng code Python đầu tiên trong đời.
- Biết cách tạo file `.py` và chạy nó bằng terminal.
- Hiểu và dùng được hàm `print()` để in chữ ra màn hình.

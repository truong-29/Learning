# Bài 06 — Hàm (functions)

> Track: Cơ bản (Beginner) · Module 1 · Bài 06

## 🎯 Mục tiêu bài học
- Hiểu hàm là gì và vì sao hàm giúp code gọn, dễ tái sử dụng.
- Định nghĩa hàm bằng `def` và gọi hàm.
- Truyền dữ liệu vào hàm qua tham số (parameters).
- Trả kết quả ra khỏi hàm bằng `return`.
- Dùng tham số mặc định và hiểu phạm vi biến (scope).

# Bài 10 — Đọc/ghi file văn bản · Bài tập

> Track: Cơ bản (Beginner) · Module 1 · Bài 10
>
> **Độ khó: Trung bình (Medium)**

Các bài này kết hợp đọc/ghi file với xử lý chuỗi và JSON. Suy nghĩ về việc file có thể chưa tồn tại.

1. Viết chương trình đọc một file văn bản và đếm tổng số từ trong file (gợi ý: đọc toàn bộ, dùng `split()`).
2. Viết "danh bạ" đơn giản: lưu danh sách liên hệ (list các dict `{"ten":..., "sdt":...}`) vào file JSON. Chương trình cho phép thêm 1 liên hệ mới rồi lưu lại, và in ra toàn bộ danh bạ.
3. Đọc một file văn bản, tạo ra file mới có nội dung giống hệt nhưng mỗi dòng được đánh số thứ tự ở đầu (ví dụ dòng đầu thành `1: nội dung`).

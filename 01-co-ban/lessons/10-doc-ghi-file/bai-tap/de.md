# Bài 10 — Đọc/ghi file văn bản · Bài tập

> Track: Cơ bản (Beginner) · Module 1 · Bài 10
>
> **Độ khó: Dễ (Easy)**

Làm lần lượt 5 bài để nắm chắc `open`, `with`, các chế độ `r`/`w`/`a`, và JSON cơ bản. Gõ tay, không copy-paste. Nếu bí, xem [gợi ý hướng dẫn](../goi-y/huong-dan.md).

1. Ghi một câu bất kỳ vào file `hello.txt`, sau đó đọc lại và in ra màn hình.
2. Ghi 3 dòng tên món ăn yêu thích vào file `monan.txt` (mỗi món một dòng).
3. Đọc file `monan.txt` ở bài trên và in ra tổng số dòng (số món ăn).
4. Dùng chế độ `"a"` để thêm 2 món ăn mới vào `monan.txt` mà không làm mất các món cũ, rồi in lại toàn bộ.
5. Nhập tên và tuổi của bạn, lưu thành một dict rồi ghi ra file `profile.json`. Sau đó đọc lại file và in ra câu chào.

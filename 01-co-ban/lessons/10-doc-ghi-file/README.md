# Bài 10 — Đọc/ghi file văn bản

> Track: Cơ bản (Beginner) · Module 1 · Bài 10

## 🎯 Mục tiêu bài học
- Hiểu vì sao cần lưu dữ liệu ra file (dữ liệu không mất khi tắt chương trình).
- Biết mở file bằng `open()` và tại sao nên dùng khối `with`.
- Đọc file với `read`, `readlines`; ghi file với `write`.
- Phân biệt các chế độ mở file: `r` (đọc), `w` (ghi đè), `a` (ghi thêm).
- Làm việc cơ bản với dữ liệu JSON: `json.dump` và `json.load`.

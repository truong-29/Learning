# Bài 08 — Dictionary & Set

> Track: Cơ bản (Beginner) · Module 1 · Bài 08

## 🎯 Mục tiêu bài học
- Hiểu dictionary lưu dữ liệu theo cặp key–value như thế nào.
- Truy cập, thêm, cập nhật và xóa phần tử trong dictionary.
- Duyệt qua dictionary bằng vòng lặp.
- Hiểu set là gì và ứng dụng loại bỏ trùng lặp, phép toán tập hợp.
- Phân biệt khi nào dùng list, dictionary hay set.

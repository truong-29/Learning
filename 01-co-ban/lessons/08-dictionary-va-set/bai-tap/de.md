# Bài 08 — Bài tập

> Track: Cơ bản (Beginner) · Module 1 · Bài 08
> Độ khó: Dễ (Easy)

Làm lần lượt các bài dưới đây. Sau khi tự làm, nếu bí, xem [gợi ý hướng dẫn](../goi-y/huong-dan.md) (không phải lời giải sẵn).

1. Tạo dictionary lưu thông tin bản thân (tên, tuổi, sở thích) và in từng cặp key–value.
2. Tạo dictionary điểm 3 môn, in ra điểm môn Toán, rồi cập nhật điểm môn đó.
3. Thêm một môn mới vào dictionary điểm ở bài 2, sau đó xóa một môn.
4. Cho list `[1, 2, 2, 3, 4, 4, 5]`, dùng set để in ra các giá trị không trùng lặp.
5. Cho hai set `{1, 2, 3}` và `{2, 3, 4}`, in ra phần giao và phần hợp của chúng.

# Bài 05 — Vòng lặp (for, while)

> Track: Cơ bản (Beginner) · Module 1 · Bài 05

## 🎯 Mục tiêu bài học
- Hiểu vòng lặp là gì và khi nào cần dùng.
- Dùng thành thạo vòng lặp `for` cùng hàm `range()`.
- Dùng vòng lặp `while` khi chưa biết trước số lần lặp.
- Điều khiển vòng lặp bằng `break` và `continue`.
- Viết được vòng lặp lồng nhau (vòng lặp trong vòng lặp).

# Bài 03 — Toán tử & Input/Output

> Track: Cơ bản (Beginner) · Module 1 · Bài 03

## 🎯 Mục tiêu bài học
- Dùng thành thạo các toán tử số học: `+  -  *  /  //  %  **`.
- Dùng toán tử so sánh (`==`, `!=`, `<`, `>`, `<=`, `>=`) để tạo ra `True`/`False`.
- Kết hợp điều kiện bằng toán tử logic: `and`, `or`, `not`.
- Nhận dữ liệu từ người dùng bằng hàm `input()`.
- In kết quả đẹp và tiện bằng **f-string**.

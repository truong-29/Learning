# Track 02 — TRUNG CẤP (Intermediate)

> Trình độ: Intermediate · Điều kiện: đã xong Track 01 — Cơ bản.
> Mục tiêu: viết code **Pythonic**, tổ chức dự án nhiều file, dùng thư viện, viết test.

Track này biến bạn từ "viết được Python" thành "viết Python đúng chuẩn nghề". Trọng tâm: tư duy Pythonic, OOP sâu, xử lý dữ liệu thực tế, công cụ và quy trình của lập trình viên.

## Lộ trình bài học

| # | Bài | Mục tiêu chính |
|---|-----|----------------|
| 01 | Comprehensions | list/dict/set comprehension, generator expression — viết gọn và nhanh |
| 02 | Hàm nâng cao | `*args`, `**kwargs`, lambda, hàm bậc cao (`map`/`filter`/`sorted` với `key`) |
| 03 | Xử lý ngoại lệ nâng cao | cây exception, tự định nghĩa Exception, `raise ... from` |
| 04 | OOP nâng cao | kế thừa, đa hình, `super()`, magic methods (`__str__`, `__eq__`), `@property` |
| 05 | Module & Package | tổ chức dự án nhiều file, `import`, `venv`, `pip`, cấu trúc project |
| 06 | Dữ liệu có cấu trúc | JSON, CSV, đọc/ghi và chuyển đổi dữ liệu thực tế |
| 07 | Iterator & Generator | `iter`/`next`, `yield`, lazy evaluation, tiết kiệm bộ nhớ |
| 08 | Decorator & Closure | closure, decorator, `functools.wraps` |
| 09 | Thư viện chuẩn hữu ích | `datetime`, `collections` (Counter/defaultdict/namedtuple), `itertools` |
| 10 | Regular Expression | module `re`, tìm/khớp/thay thế mẫu chuỗi |
| 11 | Testing & Debugging | `pytest`, unit test, debug bằng breakpoint |
| 12 | Dự án Trung cấp | xây một ứng dụng CLI hoặc API client hoàn chỉnh, có test |

# Track 03 — NÂNG CAO (Advanced)

> Trình độ: Advanced · Điều kiện: đã xong Track 02 — Trung cấp.
> Mục tiêu: giải thuật, hiệu năng, lập trình đồng thời, kiến trúc — trình độ đi phỏng vấn và làm dự án lớn.

Track này tập trung vào tư duy khoa học máy tính và kỹ thuật chuyên sâu, giúp bạn giải được bài khó, tối ưu hệ thống và thiết kế code chuyên nghiệp.
